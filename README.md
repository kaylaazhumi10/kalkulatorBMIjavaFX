# Kalkulator BMI (Body Mass Index) - JavaFX

Aplikasi desktop sederhana untuk menghitung Indeks Massa Tubuh (BMI) menggunakan JavaFX dan SceneBuilder.

## Deskripsi Singkat
Aplikasi ini memungkinkan pengguna untuk memasukkan berat badan (kg) dan tinggi badan (cm) untuk menghitung nilai BMI serta menentukan kategori kesehatan tubuh (Underweight, Normal, Overweight, Obesitas).

## Prasyarat (Prerequisites)
- JDK 17 atau lebih baru
- Apache NetBeans IDE
- JavaFX SDK / Scene Builder
- Maven
